# 🎬 Media Scraper Tool

যেকোনো ওয়েবপেজের URL দিলে সেই পেজের **ভিডিও**, **অডিও** এবং **ছবির** সব URL আলাদা ট্যাবে দেখায়।

## ✨ বৈশিষ্ট্য

- ✅ ভিডিও URL — আলাদা ট্যাবে
- ✅ অডিও URL — আলাদা ট্যাবে
- ✅ ছবি URL — আলাদা ট্যাবে (থাম্বনেইল প্রিভিউ সহ)
- ✅ প্রতিটি URL কপি করার বাটন
- ✅ নতুন ট্যাবে URL খোলার বাটন
- ✅ প্রতিটি ট্যাবে মোট কাউন্ট দেখায়
- ✅ কোনো এক্সটার্নাল ডিপেন্ডেন্সি নেই — শুধু Python স্ট্যান্ডার্ড লাইব্রেরি

## 🚀 কিভাবে চালাবেন

### পদ্ধতি ১: run.bat (সহজ উপায়)

1. `media-scraper` ফোল্ডারে যান
2. `run.bat` ফাইলে **ডাবল-ক্লিক** করুন
3. ব্রাউজারে `http://localhost:8000` খুলুন

### পদ্ধতি ২: কমান্ড লাইন

```bash
cd media-scraper
python server.py
```

তারপর ব্রাউজারে খুলুন: **http://localhost:8000**

## 📖 ব্যবহারের নিয়ম

1. URL ইনপুট বক্সে যেকোনো ওয়েবপেজের URL লিখুন (যেমন: `https://example.com`)
2. **Scrape** বাটনে ক্লিক করুন (বা Enter চাপুন)
3. ফলাফল তিনটি ট্যাবে দেখুন:
   - 🎥 **ভিডিও** — ভিডিও ফাইল ও এমবেডেড ভিডিওর URL
   - 🎵 **অডিও** — অডিও ফাইলের URL
   - 🖼️ **ছবি** — ছবির URL (প্রিভিউ সহ)

## 🔧 API

সরাসরি API থেকেও ব্যবহার করতে পারেন:

```
GET /api/scrape?url=https://example.com
```

**রেসপন্স:**
```json
{
  "url": "https://example.com",
  "title": "পেজের টাইটেল",
  "videos": ["https://...", "..."],
  "audios": ["https://...", "..."],
  "images": ["https://...", "..."]
}
```

## ⚠️ নোট

- শুধুমাত্র **শিক্ষামূলক** ব্যবহারের জন্য
- কিছু ওয়েবসাইট স্ক্র্যাপিং ব্লক করতে পারে (403 error)
- কিছু ওয়েবসাইটে JavaScript দিয়ে লোড হওয়া কনটেন্ট পাওয়া নাও যেতে পারে
- কপিরাইটযুক্ত কনটেন্ট ডাউনলোড করা আইনত নিষিদ্ধ হতে পারে

## 🛠️ প্রয়োজনীয়তা

- **Python 3.6+** (কোনো এক্সটার্নাল প্যাকেজ লাগবে না)
- যেকোনো আধুনিক ব্রাউজার (Chrome, Firefox, Edge)
